# Операции магазина

## Склад и остатки

**Правило продукта:** у каждого магазина один операционный склад (default warehouse). Пользователь **не выбирает** склад при создании заказа, продажи, приёмки, списания или инвентаризации.

API: `OrganizationUseCases.resolveStoreWarehouse()` — находит или создаёт default warehouse.

Backoffice: формы создания не содержат picker склада; nav «Остатки» ведёт на `/stores/{id}/stock`.

Технический склад виден только в карточке магазина (код `MAIN`).

## Store scope

- URL с `:storeId` проверяется `StoreScopeGuard`
- Список магазинов org фильтруется для пользователей с `SELECTED_STORES`
- Director с `ALL_STORES` видит все магазины организации

## Основные разделы магазина

| Раздел | Путь | Назначение |
|--------|------|------------|
| Смена / Home | `/home` | KPI, очередь, attention |
| Заказы | `/orders` | Очередь по фазам |
| Продажи | `/sales` | Касса, чеки |
| Приёмки | `/supplies` | Поступление товара |
| Остатки | `/stock` | Балансы и партии |
| Доставки | `/deliveries` | Board, карта |
| Настройки | `/settings` | Профиль магазина |
